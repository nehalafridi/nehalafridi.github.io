# Financial Data Analysis with R

## About the Project

This project explores financial data from a sample of banking and finance companies using R.

The goal is to practice data analysis, statistical calculations, data visualization, and financial interpretation.

## Tools Used

- R
- RStudio
- Statistics
- Data Analysis
- Data Visualization

## Analysis Performed

- Calculated total and average revenue
- Calculated average, highest, and lowest profit
- Calculated profit margins
- Compared Banking and Finance sectors
- Identified the company with the highest profit
- Created a Revenue vs Profit scatter plot
- Calculated the correlation between revenue and profit
- Used summary statistics to understand the dataset

## Key Findings

- Epsilon Bank had the highest profit in the sample.
- Banking companies had higher average revenue and profit than Finance companies in this sample.
- Revenue and profit showed a strong positive correlation.
- The correlation between revenue and profit was approximately 0.98.

## Important Note

The dataset used in this project is a practice dataset created for learning and demonstration purposes. The findings should not be interpreted as representing the actual banking or finance industry.
